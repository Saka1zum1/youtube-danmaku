# YouTube 彈幕

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md)

把 YouTube 直播聊天轉成影片上滾動彈幕的油猴腳本。互動與翻譯架構參考 [Twitch Danmaku](https://github.com/Saka1zum1/twitch-danmaku)（MIT），播放器與聊天則改為讀取 YouTube 觀看頁。

## 功能

- **即時彈幕** — 直播聊天的新訊息在畫面上滾動
- **發送者配色** — 滾動時只顯示內容；每位使用者顏色固定，房主 / 管理員沿用身份色
- **互動暫停** — 懸停或點擊暫停；點擊可看發送者，翻譯過的彈幕會附上原文
- **複製到聊天室** — 提示框的複製按鈕把文字寫入直播聊天輸入框
- **朗讀** — 可選擇朗讀新彈幕。控制列圖示用來打開朗讀面板；音量為 0 時圖示變成靜音。純符號、純表情、純數字不朗讀，重複內容最多讀 3 遍
- **自訂** — 速度、字型、透明度、滾動區域（全螢幕 / 上半部 / 頂部 1/4）
- **全螢幕自適應** — 跟隨播放器縮放、劇院模式與全螢幕
- **即時翻譯** — Microsoft、Google、火山翻譯、彩雲小譯、騰訊互動翻譯。尖峰時合併請求，被限流的引擎會先跳過。純數字與符號不翻譯
- **手動翻譯單則** — 在嵌套聊天裡右鍵訊息可翻譯 / 重新翻譯；失敗時會切換其他引擎重試
- **聊天右鍵選單** — 右鍵可翻譯、朗讀、發成彈幕、加入收藏，或開啟發送者頻道
- **收藏與獨輪車** — 聊天輸入旁的星號可收藏常用句子，一鍵送出或數字快捷鍵；也可定時隨機送出（獨輪車）
- **清空聊天** — 聊天標題列一鍵清空目前列表，不必關掉聊天
- **收起 / 展開聊天** — 收起側邊聊天讓影片變寬；可用側邊按鈕或播放器控制列恢復
- **全螢幕發聊天** — 直播全螢幕時按 Enter 打開輸入框，送出後仍留在全螢幕
- **Super Chat 懸停** — 可選在頂部或底部固定展示，帶頭髮像、截斷使用者名稱、金額徽章，顏色貼近 YouTube。多則可同時出現且互不遮擋；過長正文在氣泡內滾動
- **Super Chat 操作** — 點擊 Super Chat（或詳情卡片）可翻譯、朗讀、發成彈幕或收藏
- **同時觀看人數** — 直播有資料時，在 Live 徽章旁顯示同時觀看與總觀看
- **防堆積** — 進房時已在列表中的訊息，以及其後約 2.5 秒內的訊息，不會一次刷出
- **介面語言** — 跟隨瀏覽器語言（中文 / 英文 / 日文）

## 安裝

1. 安裝 [Tampermonkey](https://www.tampermonkey.net/)
2. 用油猴開啟 [`dist/youtube-danmaku.user.js`](dist/youtube-danmaku.user.js)，或把檔案內容貼進新腳本後儲存
3. 若腳本沒有執行，請在瀏覽器的擴充功能設定中允許使用者腳本

或從原始碼建置：

```bash
git clone <this-repository>
cd youtube-danmaku
npm run build
```

建置結果是 `dist/youtube-danmaku.user.js`。

## 使用

1. 開啟有直播聊天或聊天重播的 YouTube 觀看頁（`/watch` 或 `/live/...`）
2. 聊天保持嵌在頁面右側。腳本讀取 `ytd-live-chat-frame#chat` 裡的 `iframe#chatframe`。彈出的獨立聊天視窗不會被監聽
3. 新訊息在 `ytd-player #movie_player` 的 `.html5-video-container` 上滾動
4. 播放器右側控制組最左邊會多出按鈕：
   - **彈幕** — 開關滾動
   - **朗讀** — 打開朗讀面板
   - **下載** — 匯出歸檔聊天重播
   - **設定** — 打開選項
   - **展開聊天** — 收起側邊聊天後出現，用來恢復
5. 懸停一則彈幕會暫停；點擊可看是誰發的
6. 點複製圖示後，文字會進入直播聊天輸入框，仍需自己送出。點朗讀圖示則只朗讀這一則
7. 懸停時，指標離開約 0.3 秒後繼續滾動；點擊鎖定後，點提示框外面才會繼續
8. 右鍵聊天訊息可翻譯 / 朗讀 / 發彈幕 / 收藏 / 開啟主頁；點擊 Super Chat 也有同類操作。標題列可清空或收起聊天；全螢幕時按 Enter 可輸入

## 設定

| 選項 | 說明 |
|------|------|
| 滾動速度 | 1–10，越大越快 |
| 字型大小 | 14–40 px |
| 彈幕透明度 | 10–100% |
| 朗讀 | 預設關閉。面板裡設定聲音、音量、音高和語速。音量為 0 時圖示顯示靜音 |
| 變速模式 | 單則超出最長朗讀時間時自動加快。開啟翻譯後按譯文長度計算 |
| 字型 | 18 種系統字型 |
| 滾動區域 | 全螢幕 / 上半部 / 頂部 1/4 |
| Super Chat 懸停 | 在頂部或底部固定展示付費訊息，可多則並存 |
| 懸停時間 / 動畫 | 每則停留多久，以及進入／退出動畫 |
| 啟用翻譯 | 畫面上彈幕改為顯示譯文 |
| 在聊天區顯示譯文 | 可選：聊天區保留原文，並在下方用區分樣式顯示譯文 |
| 翻譯引擎 | 自動切換 / Microsoft / Google / 火山翻譯 / 彩雲小譯 / 騰訊互動翻譯 |
| 目標語言 | 來源語言自動偵測 |
| 翻譯速度 | 1–10 則/秒。忙碌時多則會合成較少的請求 |

## 聊天紀錄

聊天需嵌在頁面右側。**直播中**下載會匯出目前聊天框裡已顯示的訊息（含 `9:40 PM` 這類時鐘時間戳）。**重播**則讀取完整聊天重播（與 yt-dlp 寫出的 `live_chat` 同類資料），長任務可暫停、繼續或取消。面板裡可以按關鍵詞和使用者名稱篩選、選擇是否包含 Super Chat、在重播上截取時間範圍，並匯出 CSV、JSON 或 TXT。

設定存在本機，下次開啟仍然有效。

## 開發

```bash
npm run build
npm run watch
```

公開演示不需要建置：[YouTube 彈幕演示](https://saka1zum1.github.io/youtube-danmaku/)。它用頁面代替觀看頁（播放器、控制列、聊天列表）。列表裡已有的訊息不會滾動；預熱結束後新加的訊息會從畫面上飄過。可試用朗讀、收藏、清空／收起聊天、右鍵操作和 Super Chat 範例。預覽頁在瀏覽器分頁位於背景時也會繼續跑。

## 注意事項

- 支援的是桌面版 `youtube.com` 觀看頁。腳本也會符合 `m.youtube.com`，但行動版播放器結構可能不同
- 翻譯會請求 Microsoft、Google、火山、彩雲或騰訊，部分地區需要代理
- YouTube 改版後，聊天讀取或控制列按鈕可能失效，歡迎回報
