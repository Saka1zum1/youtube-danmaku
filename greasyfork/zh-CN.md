## 简介

YouTube 弹幕让你在看 YouTube 直播或聊天回放时，把直播聊天里的新消息变成视频上滚动的弹幕——就像 B 站那样。

不用一直盯着右侧聊天框，重要评论从画面上飘过，一目了然。

## 使用方法

1. 安装 Tampermonkey 扩展
2. 安装本脚本后，打开带直播聊天或聊天回放的 YouTube 观看页（`/watch` 或 `/live/...`）
3. 聊天保持嵌在页面右侧。弹出的独立聊天窗口不会被读取
4. 播放器右侧控制栏最左边会出现新按钮：
   - **弹幕按钮** — 一键开关弹幕
   - **朗读按钮** — 打开朗读面板
   - **下载按钮** — 导出归档聊天回放
   - **设置按钮** — 打开设置面板
   - **展开聊天** — 收起侧边聊天后出现，用来恢复
   - **增强画中画** — 打开带画面和弹幕的小窗口
5. 在面板中调整样式、开启朗读或开启翻译

**小技巧：** 看到感兴趣的弹幕？鼠标移上去就能暂停阅读；点击还能查看发送者。在弹窗里点复制，可以把内容写入直播聊天输入框，仍需自己发送。点朗读则只读这一条。右键聊天消息可翻译、朗读、发弹幕、收藏或打开主页；点击 Super Chat 也有同类操作。标题栏可清空或收起聊天；全屏时按 Enter 可输入。

### 实时弹幕

- 自动捕获直播聊天和聊天回放里的新消息，在视频上滚动显示
- 只显示消息内容。每个发送者颜色稳定，房主和管理员沿用身份色
- 悬停或点击任意弹幕可暂停滚动
- 点击弹出弹窗显示发送者；在弹窗中点击复制按钮，将弹幕内容写入右侧聊天输入框。朗读按钮只读这一条
- 右键消息可翻译 / 重新翻译、朗读、发成弹幕、收藏或打开主页；翻译失败时会切换其他引擎重试

### 收藏与独轮车

- 聊天输入旁的星标可收藏常用句子
- 支持一键发送、数字快捷键，以及定时随机发送（独轮车）

### 清空与收起聊天

- 标题栏可一键清空当前聊天列表，不必关掉聊天
- 可收起侧边聊天让视频变宽，再用侧边按钮或播放器控制栏展开

### 全屏发聊天

- 直播全屏时按 Enter 打开输入框，发送后仍留在全屏

### 增强画中画

- 播放器按钮打开小窗口，同时显示画面和弹幕
- 可开关弹幕、打开设置、发送聊天（含收藏）、锁定比例或铺满、刷新画面，或回到视频页
- 小窗口开着时，切到其他标签页，聊天和弹幕也会继续
- 需要 Chrome 或 Edge 116 及以上

### Super Chat

- 可选在播放器顶部、四角或底部固定展示
- 完整模式：头像、用户名、金额与正文；精简模式：头像、截断用户名与金额，点击弹出详情卡片查看全文
- 最多可同时展示十条；悬停时间可跟随 YouTube 聊天栏 ticker，也可手动设置
- 可选让悬停条盖在滚动弹幕之上
- 点击 Super Chat（或详情卡片）可翻译、朗读、发成弹幕、收藏或打开主页

### 同时观看人数

- 直播有数据时，在 Live 徽章旁显示同时观看与总观看

### 朗读

- 控制栏图标用来打开朗读面板，在面板里开启朗读。音量调到 0 时，图标变为静音
- 可设置声音、音量、音高和朗读速度
- 变速模式会在单条超出最长朗读时间时自动加快。开启翻译后按译文长度计算
- 纯符号、纯表情、纯数字不朗读。重复内容最多读 3 遍
- 聊天太忙时只保留最新的若干条，避免朗读一直追不上

### 聊天记录

- 直播中导出当前聊天框里已显示的消息（含墙钟时间戳）；回放则读取完整聊天回放，可暂停/继续/取消
- 可按关键词和用户名筛选。留空表示不使用该项筛选
- 可选择是否包含 Super Chat，回放可用进度条截取时间范围，并导出 CSV、JSON 或 TXT
- 没有可导出内容，或读取失败时，面板会给出提示

### 自定义样式

- 滚动速度、字体大小、弹幕透明度（10–100%）、字体种类（18 种系统字体）
- 滚动区域：全屏 / 上半屏 / 下半屏 / 顶部 1/4
- Super Chat 悬停位置、精简模式、停留时间（手动或跟随 YouTube）、遮挡弹幕选项与动画
- 关键词屏蔽。原文或译文包含关键词时，这条弹幕不会出现
- 全屏、剧场模式、调整窗口大小时自动适配

### 实时翻译（可选）

- 引擎可选自动切换、Microsoft、Google、火山翻译、彩云小译、腾讯交互翻译
- 源语言自动检测，译文直接替换弹幕内容
- 可选：在聊天区保留原文，并在下方用区分样式显示译文
- 支持右键手动翻译单条，重新翻译时会切换引擎重试
- 可自选目标语言与翻译速度
- 纯数字和符号不翻译；聊天高峰时会合并请求

### 贴心细节

- 进入直播间不会刷出一屏历史弹幕
- 切换标签页回来后不会集中爆发
- 界面自动识别浏览器语言（中文 / 英文 / 日文）
- 零外部依赖，轻量不拖慢页面

## 常见问题

**Q: 翻译不工作？**
A: 翻译会请求 Microsoft、Google、火山、彩云或腾讯，具体取决于所选引擎。部分地区可能需要网络代理。

**Q: 没有弹幕？**
A: 请打开带直播聊天或聊天回放的观看页，并让聊天嵌在页面右侧。弹出的独立聊天窗口读不到。没有直播聊天的普通视频不会出现弹幕。

**Q: 弹幕太多看不清？**
A: 可在设置中调慢速度、缩小滚动区域，或直接关闭弹幕。

**Q: 支持哪些浏览器？**
A: 支持 Tampermonkey 的 Chromium、Firefox、Safari 等主流浏览器。桌面版 youtube.com 观看页是主要支持的版面。

## 隐私说明

- 本脚本仅在 YouTube 页面运行
- 开启翻译后，待译文本会发送至当前所选引擎（Microsoft、Google、火山翻译、彩云小译或腾讯交互翻译）
- 设置保存在浏览器本地，不上传其他数据
