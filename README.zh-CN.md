# YouTube 弹幕

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md)

把 YouTube 直播聊天转成视频上滚动弹幕的油猴脚本。交互和翻译架构参照 [Twitch Danmaku](https://github.com/Saka1zum1/twitch-danmaku)（MIT），播放器与聊天读取改为 YouTube 观看页。

## 功能

- **实时弹幕** — 直播聊天的新消息在画面上滚动
- **发送者配色** — 滚动时只显示内容；每个用户颜色稳定，房主 / 管理员沿用其身份色
- **交互暂停** — 悬停或点击暂停；点击可看发送者，翻译过的弹幕会附上原文
- **复制到聊天框** — 提示框里的复制按钮把文字写入直播聊天输入框
- **朗读** — 可选地朗读新弹幕。控制栏图标用来打开朗读面板；音量为 0 时图标变为静音。纯符号、纯表情、纯数字不朗读，重复内容最多读 3 遍
- **自定义** — 速度、字体、透明度、滚动区域（全屏 / 上半屏 / 下半屏 / 顶部 1/4）
- **全屏自适应** — 跟随播放器缩放、剧场模式和全屏
- **实时翻译** — Microsoft、Google、火山翻译、彩云小译、腾讯交互翻译。高峰时合并请求，被限流的引擎会先跳过。纯数字和符号不翻译
- **手动翻译单条** — 在嵌套聊天里右键消息可翻译 / 重新翻译；失败时会切换其他引擎重试
- **聊天右键菜单** — 右键可翻译、朗读、发成弹幕、加入收藏，或打开发送者主页
- **收藏与独轮车** — 聊天输入旁的星标可收藏常用句子，一键发送或数字快捷键；也可定时随机发送（独轮车）
- **清空聊天** — 聊天标题栏一键清空当前列表，不必关掉聊天
- **收起 / 展开聊天** — 收起侧边聊天让视频变宽；可用侧边按钮或播放器控制栏恢复
- **全屏发聊天** — 直播全屏时按 Enter 打开输入框，发送后仍留在全屏
- **增强画中画** — 播放器按钮打开小窗口，同时显示画面和弹幕。可开关弹幕、打开设置、发送聊天（含收藏）、锁定比例或铺满、刷新画面，或回到视频页。小窗口开着时，切到其他标签页，聊天和弹幕也会继续。需要 Chrome 或 Edge 116 及以上
- **Super Chat 悬停** — 可选在播放器顶部、四角或底部固定展示。完整模式显示头像、用户名、金额与正文；精简模式显示头像、截断用户名与金额，点击可弹出详情卡片。最多可同时展示十条。悬停时间可跟随 YouTube 聊天栏 ticker，也可手动设置。可选让悬停条盖在滚动弹幕之上
- **Super Chat 操作** — 点击 Super Chat（或详情卡片）可翻译、朗读、发成弹幕、收藏或打开主页
- **同时观看人数** — 直播有数据时，在 Live 徽章旁显示同时观看与总观看
- **防堆积** — 进房时已经在列表里的消息，以及随后约 2.5 秒内的消息，不会一次性刷出来
- **界面语言** — 跟随浏览器语言（中文 / 英文 / 日文）

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 用油猴打开 [`dist/youtube-danmaku.user.js`](dist/youtube-danmaku.user.js)，或把文件内容粘贴进新建脚本后保存
3. 若脚本没有运行，在浏览器的扩展设置里允许用户脚本

或从源码构建：

```bash
git clone <this-repository>
cd youtube-danmaku
npm run build
```

构建产物是 `dist/youtube-danmaku.user.js`。

## 使用

1. 打开带直播聊天或聊天回放的 YouTube 观看页（`/watch` 或 `/live/...`）
2. 聊天保持嵌在页面右侧。脚本读取 `ytd-live-chat-frame#chat` 里的 `iframe#chatframe`。弹出的独立聊天窗口不会被监听
3. 新消息在 `ytd-player #movie_player` 的 `.html5-video-container` 上滚动
4. 播放器右侧控制组的最左边会多出按钮：
   - **弹幕** — 开关滚动
   - **朗读** — 打开朗读面板
   - **下载** — 导出归档聊天回放
   - **设置** — 打开选项
   - **展开聊天** — 收起侧边聊天后出现，用来恢复
   - **增强画中画** — 打开带画面和弹幕的小窗口
5. 悬停一条弹幕会暂停；点击可看是谁发的
6. 点击复制图标，文字会进直播聊天输入框，仍需自己发送。点击朗读图标则只朗读这一条
7. 悬停时，指针离开约 0.3 秒后继续滚动；点击锁定后，点提示框外面才会继续
8. 右键聊天消息可翻译 / 朗读 / 发弹幕 / 收藏 / 打开主页；点击 Super Chat 也有同类操作。标题栏可清空或收起聊天；全屏时按 Enter 可输入

## 设置

| 选项 | 说明 |
|------|------|
| 滚动速度 | 1–10，越大越快 |
| 字体大小 | 14–40 px |
| 弹幕透明度 | 10–100% |
| 朗读 | 默认关闭。面板里设置声音、音量、音高和语速。音量为 0 时图标显示静音 |
| 变速模式 | 单条超出最长朗读时间时自动加快。开启翻译后按译文长度计算 |
| 字体 | 18 种系统字体 |
| 滚动区域 | 全屏 / 上半屏 / 下半屏 / 顶部 1/4 |
| Super Chat 悬停 | 固定展示付费消息；可选位置、完整/精简样式，最多十条 |
| 悬停时间 | 手动秒数，或开启「跟随 YouTube 聊天栏」 |
| 悬停遮挡弹幕 | 可选：悬停条覆盖滚动弹幕，而不挤占轨道 |
| 悬停动画 | 每条进入/退出动画 |
| 启用翻译 | 画面上弹幕改为显示译文 |
| 在聊天区显示译文 | 可选：聊天区保留原文，并在下方用区分样式显示译文 |
| 翻译引擎 | 自动切换 / Microsoft / Google / 火山翻译 / 彩云小译 / 腾讯交互翻译 |
| 目标语言 | 源语言自动检测 |
| 翻译速度 | 1–10 条/秒。忙的时候多条会合成更少的请求 |

## 聊天记录

聊天需嵌在页面右侧。**直播中**下载会导出当前聊天框里已显示的消息（含 `9:40 PM` 这类墙钟时间戳）。**回放**则读取完整聊天回放（与 yt-dlp 写出的 `live_chat` 同类数据），长任务可暂停、继续或取消。面板里可以按关键词和用户名筛选、选择是否包含 Super Chat、在回放上截取时间范围，并导出 CSV、JSON 或 TXT。

设置保存在本地，下次打开仍然有效。

## 开发

```bash
npm run build
npm run watch
```

公开演示不需要构建：[YouTube 弹幕演示](https://saka1zum1.github.io/youtube-danmaku/)。它用页面代替观看页（播放器、控制栏、聊天列表）。列表里已有的消息不会滚动；预热结束后新加的消息会从画面上飘过。可试用朗读、收藏、清空 / 收起聊天、右键操作，以及在设置里调整 Super Chat 悬停（位置、精简模式、滚动区域、跟随 ticker 等）。控制栏还可打开增强画中画（需 Chrome 或 Edge 116 及以上）。预览页在浏览器标签位于后台时也会继续跑。

## 注意事项

- 支持的是桌面版 `youtube.com` 观看页。脚本也会匹配 `m.youtube.com`，但移动版播放器结构可能不同
- 翻译会请求 Microsoft、Google、火山、彩云或腾讯，部分地区需要代理
- YouTube 改版后，聊天读取或控制栏按钮可能失效，欢迎反馈
